# Game Boy Editor

Graphics and sound editors for the original Game Boy (DMG), running in the browser. Everything exports RGBDS assembly,
GBDK-2020 C arrays or raw binaries.

| Editor | Makes |
|---|---|
| Tile Editor | 8x8 2-bit tiles (4 shades) |
| Sprite Editor | animated hardware sprites (OAM), 8x8 or 8x16 |
| Background Editor | the 32x32 background tile map, with a screen/scroll preview |
| Metatile Editor | 2x2 / 4x4 tile building blocks with collision flags |
| Level Editor | scrolling levels built from metatiles |
| Font Editor | 96 ASCII glyphs as tiles |
| Music Editor | 4-channel tracker for the sound chip (pulse x2, wave, noise) with playback |

Hover any tool or button for a tooltip. Terms: **BGP/OBP0/OBP1** are the palette registers that map shade numbers to greys,
**SCX/SCY** scroll the background, **OAM** is the hardware sprite table.

```
npm install
npm run dev
```

## Documentation and examples

The editor's **Documentation** menu has the Game Boy assembly book and a worked example for each editor.
The runnable programs behind the examples are in `examples/` (see `examples/README.md`; needs RGBDS and an emulator such
as mGBA). The example pages in `public/` are generated by `npm run docs` from `docs/pages/`. The C (GBDK) snippets and
exports are not compiled by the tests; the RGBDS exports and examples are.

## Tests

    npm test               # unit tests (Jest), with coverage
    npm run test:e2e       # end-to-end tests (Playwright, real browser; builds and starts the app itself)
    examples/verify_examples.py   # runs the example ROMs on an emulated Game Boy (needs pyboy and numpy; see examples/README.md)
