# Game Boy Editor

Graphics and sound editors for the original Game Boy (DMG). See `CLAUDE.md` for the plan.

```
npm install
npm run dev
```

## Documentation and examples

The editor's **Documentation** menu has the Game Boy assembly book and a worked example for each editor.
The runnable programs behind the examples are in `examples/` (see `examples/README.md`); the example pages in
`public/` are generated by `npm run docs` from `docs/pages/`.

## Tests

    npm test               # unit tests (Jest), with coverage
    npm run test:e2e       # end-to-end tests (Playwright, real browser; builds and starts the app itself)
    examples/verify_examples.py   # runs the example ROMs on an emulated Game Boy (see examples/README.md)
